# Ziad Beranger — Portfolio prototype

Zero-dependency static prototype for the new portfolio. The homepage hero is now the supplied original `assets/hero-home.jpg`. Project images remain temporary visual references from the existing Framer site and must be replaced with the original assets before production.

## Preview

Run a static server in this directory:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
